OK, WATCH and BREACH compare the value with the limits in the same row (green ≤ the first limit, watch ≤ the second, breach above); every status also carries a word and a glyph, so colour is never the only cue. INFO rows are reported, not limited: the Feller condition is a diagnostic here, not a no-arbitrage requirement. A BREACH is not an outage: it marks where the model is weakest, which the linked page explains.
