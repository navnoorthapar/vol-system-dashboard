C18 — a strike-rolling bug contaminated every earlier number

The straddle engine re-entered a position the same day it exited, so the position series never returned to flat: a continuously held position was one trade whose strike was fixed at first entry and whose tenor decayed to its 1-day floor, instead of a fresh 30-day ATM straddle rolled at every max-hold. The book held a single stale-strike, perpetually expiring straddle — a directional |S − K| bet, not a vol trade — and this contaminated all P&L from C10 to C17. Fixing it (forcing a flat day so straddles roll) inverted the contrarian thesis: the “catastrophic” S1 (−$1.53M) that motivated flipping its direction into S1C was the artifact.

After C18, S1 looked like a profitable short-VRP harvester (+$694K by C21). C22 showed that profit was the skew premium inside the VIX: straddles had been priced at the VIX, a 30-day variance-swap rate, not at ATM vol. Priced at {{ beta_txt }} × VIX, S1 is {{ s1.get('total_pnl')|usd_k }} ({{ s1.get('win_rate')|pct(0, false) }} win); {% if s1f %}its sign flips between β = {{ s1f.lo|fmt('.2f') }} and {{ s1f.hi|fmt('.2f') }}{% endif %}. The contrarian inversion S1C is {{ s1c.get('total_pnl')|usd_k }}, so neither direction of the PDV-spread trade makes money. The portfolio is {{ k.get('cum_ret')|pct }} cumulative (Sharpe {{ k.get('sharpe')|fmt(".2f") }}, max drawdown {{ k.get('mdd')|pct }}); S3 ({{ s3.get('total_pnl')|usd_k }}, {{ s3.get('win_rate')|pct(0, false) }} win) is the only positive sleeve, {{ s3_beta_txt }}, and below the T-bill return.

S3 · dispersion (index leg) fires only at VIX/VVIX extremes: {{ s3.get('n_trades')|fmt }} trades in {{ yrs }}{% if s3.get('rolls') %} ({{ s3.entries }} entries plus {{ s3.rolls }} rolls of a position held past its straddle's expiry){% endif %}, {{ s3.get('win_rate')|pct(0, false) }} win rate. Since C22 it is priced as the index leg of the dispersion trade (a short SPX straddle; there is no single-stock options data), and {{ s3_timing_txt }}. The pre-C22 “+$23K at every z-scale” was not option P&L.

Limitations and what would lift them

Option prices. All P&L is Black–Scholes on β·VIX — the database holds no option prices inside the backtest window{% if d.option_snapshots and d.option_snapshots.dates %} (its {{ d.option_snapshots.dates|length }} SPX chain{{ 's' if d.option_snapshots.dates|length != 1 else '' }}, {{ "{:,}".format(d.option_snapshots.n_rows) }} rows, are snapshots from {{ d.option_snapshots.dates[0] }}{% if d.option_snapshots.dates|length > 1 %} to {{ d.option_snapshots.dates[-1] }}{% endif %}{% if be %}; β comes from {{ be.n_db }} of them plus a live capture, and {{ be.later|length }} {{ 'is a later check' if be.later|length == 1 else 'are later checks' }}{% endif %}){% endif %}. Historical end-of-day chains would turn the backtest from an estimate into evidence.

Jumps. The one Bates SVJ fit did not converge (λ ended at its bound and the fit was worse than nested Heston), and daily returns cannot separate frequent small jumps from rare large ones; intraday data (bipower variation) would.

Breadth. S3 {% if s3.get('rolls') %}enters {{ s3.entries }} times{% else %}trades {{ s3.get('n_trades')|fmt }} times{% endif %} in {{ yrs }}; by the fundamental law of active management that breadth cannot support an information ratio. Single-name option data across index constituents would.

Execution. Costs are a flat assumption; quote-level bid–ask data would test whether a thin vol-carry edge survives the round trip. The Monte-Carlo-priced Quintic OU calibration is slow (see the calibration page).
