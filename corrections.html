C16

Methodology audit: look-ahead, a circular feature, retrospective sizing

high severity 5 findings 2026-06-11
Detection
Self-audit of the methodology before the result was published.
Components · commits

Effect on the published result

Finding 1 · fixed PDV look-ahead bias
Root cause
The PDV model was fitted on the full sample, so every backtest year traded a forecast that had seen its own future.
Fix
PDVLinear refitted per backtest year on strictly earlier returns (walk-forward) before it feeds the pdv_iv_spread feature.
Evidence
S1/S1C now trade a causal PDV forecast
Pinned by
test_pdv.py::TestNoLookAhead::test_walk_forward_no_lookahead_poison, test_pdv.py::TestNoLookAhead::test_poison_actually_bites_later

Root cause
vvix was a training feature while the R2 label is defined as VVIX above a threshold, so 86.2% accuracy partly measured rule recovery.
Fix
vvix removed from the classifier's features; honest accuracy 63.4%.
Evidence
Historical C16 figure: honest accuracy 63.4%; C17 then found it lost to the persistence baseline
Pinned by
test_regime_classifier.py::TestVersionRobustPickle::test_shipped_classifier_is_built_on_the_canonical_gate
Finding 3 · fixed Retrospective Kelly netting
Root cause
Correlation and Sharpe multipliers used same-day P&L to size the same day's positions.
